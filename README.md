# BitRush

Новый независимый дизайн на React + Vite. Редакционный/швейцарский стиль: огромная типографика, светлая основа, сплошная горизонтальная обменная форма и контрастные секции. В отличие от предыдущих вариантов калькулятор расположен отдельной полноширинной полосой ниже большого заголовка, а не в карточке справа от текста.

## Запуск

```bash
npm install
npm run dev
```

## Сборка и Cloudflare Pages

```bash
npm run build
```

Framework preset: Vite; build command: `npm run build`; output directory: `dist`.

## Важно

- Telegram URL задаётся через `TELEGRAM_URL` в `src/App.jsx` (сейчас `https://letsmon.xyz/4i1jj4jxzqpp`).
- Курсы фиатных валют загружаются с currency-api, криптовалют — CoinGecko. Если API недоступны, показываются демонстрационные значения с явной пометкой. Все цифры — предварительный расчёт, не окончательная оферта.
- Настоящие котировки/наценку и бизнес-логику обязательно согласовать до коммерческого запуска. Текущие коэффициенты оставлены для совместимости с предыдущим калькулятором, а не как обещание реальных условий.
- Форма не собирает персональные данные на сервере: город и параметры заявки передаются через ссылку на Telegram.
- Проект отдельный и не меняет старые репозитории.
